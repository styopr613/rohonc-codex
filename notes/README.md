# Working documents

These are not part of the edition. They are the briefs the work was done from:
written for whoever ran the next stage, kept accurate rather than tidy, and
left as they were written rather than smoothed afterwards. They argue with
earlier versions of themselves, and that is deliberate — when a figure in one
of them turned out to be wrong, the wrong one stayed on the page beside the
right one.

They are here because a reader who wants to know how a reading was arrived at
should be able to read the instruction that produced it. Nothing in this
directory is read by any program, and nothing in it overrides
[`METHOD.md`](../METHOD.md), which is the standing order for the project and
stays at the repository root.

## The Rohonc briefs, in the order they were written

| file | what it is |
|---|---|
| [`CODEX_REWRITE.md`](CODEX_REWRITE.md) | the brief for making Book One read as English, with its readability targets fixed before the rewrite began |
| [`FINALPASS.md`](FINALPASS.md) | why the vocabulary had to be checked before the bracketed guesses were, and what that ordering changed |
| [`BLINDFOLD.md`](BLINDFOLD.md) | instructions for a stranger to run the one check the project cannot run on itself. Written to be handed to someone who has not read anything else here |
| [`DARK.md`](DARK.md) | the last 3.6% of the manuscript that had no reading at all, how it was closed, and what the attempt taught. Complete: there are no dark words left |
| [`fix.md`](fix.md) | what to do when a reading is hardened and the prose that quoted it no longer matches. The count of how much of Book One is exposed to that, and the two legitimate fixes |

| file | what it is |

`PREDICTION_abbrev.md` is the only file in here that is evidence rather than
instruction. It is kept because a pre-registration is worth nothing unless the
record shows it was written first.
